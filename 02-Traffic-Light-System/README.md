# SMART TRAFFIC LIGHT SYSTEM

## Features

- Red, Blue & Green LEDs to indicate stop, ready and go
- Push Button i.e automatic traffic cycle that lets pedestrians go accross just by a simple push button
- Active buzzer

## Components

- Arduino UNO R4 Lite
- Breadboard
- 3 LEDs
- Push Button
- Active Buzzer
- Jumper Wires
- 220Ω Resistors

## Pin Configuration

| Component | Arduino Pin |
|-----------|-------------|
| Red LED | D13 |
| Blue LED | D12 |
| Green LED | D11 |
| Buzzer | D8 |
| Button | D2 |
